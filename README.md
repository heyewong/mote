# Mote：贴着你的笔记思考，属于你的 Obsidian 随身 AI 助理

### 为什么选择 Mote？

大多数 AI 工具都活在另一个浏览器标签页里。你不得不从 Obsidian 复制一段笔记，粘贴进 AI 工具，费劲解释半天前因后果，再把结果拷回来手动排版。在手机上，这个过程更是令人崩溃。

**Mote 把 AI 真正带进了你的知识库。**

无论你是在电脑前梳理复杂项目，还是在路上捕捉灵感，Mote 都能在你的 Vault 旁边贴身协作。它基于你选定的笔记上下文思考、帮你建立关联、起草修改建议——而最终的确认键，始终握在你手里。

---

### 核心亮点

- **懂你所写（笔记上下文直通）**：基于你选定的笔记回答问题。Mote 可以按你的授权检索与阅读 Vault 中的内容，让 AI 真正基于你沉淀的资料为你服务。
- **先展示建议，由你决定（完全掌控感）**：无论是扩写、润色还是新建文件，Mote 都会先把提议交给你审阅，再由你决定是否写入。
- **电脑与手机统一的流畅体验（原生适配）**：专为桌面端与移动端 Obsidian 打造。从大屏到手机，随时打开你的知识库继续思考。
- **自备 API 密钥（BYOK）**：使用你自己的 AI 服务商账户和 API Key，直接选择并连接模型服务，无需购买捆绑的模型套餐。

### 真实使用感受

> **你：** “看一眼我的项目记录，帮我整理出明天会议需要对齐的 3 个核心待办。”
>
> **Mote：** 阅读相关笔记，提取行动项，并给出一份 Markdown 草案供你审阅。

> **你（在手机上）：** “把这段随手记下的项目想法整理成结构化清单。”
>
> **Mote：** 梳理思路、提取待办，并询问你是否需要写入当前的项目笔记。

### 极简 3 步上手

1. **安装插件**：在 [Releases](../../releases) 页面下载最新安装包，或通过 BRAT 安装。
2. **填入 Key**：打开 Obsidian 设置 → **Mote**，选择 AI 服务商并粘贴 API Key。
3. **开始协同**：打开 Mote 侧边栏或手机快捷入口，开始与你的笔记对话。

首次启动 Mote Agent 后，可享 **14 天全功能免费试用**。

---

### 隐私承诺与 BYOK：干净、坦荡、属于你

- **不采集遥测、没有广告**：Mote 默认不采集遥测，也没有广告。
- **使用你选择的 AI 服务商**：提示词和你带入的笔记上下文会发送给你配置的 Provider，以便生成回答。
- **密钥妥善保存**：API Key 通过 Obsidian SecretStorage 保存。
- **安全写入审批**：Mote 提出 Vault 写入建议，由你审阅并决定是否批准。
